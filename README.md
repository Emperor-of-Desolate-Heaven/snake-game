# 贪吃蛇 🐍

一个用 Python 标准库 turtle 编写的经典贪吃蛇游戏，零第三方依赖，双击即玩。

## 运行

```bash
py snake.py
```

（需要 Python 3，Windows 上可用 `python snake.py` 或 `python3 snake.py`）

## 操作说明

| 按键 | 功能 |
|------|------|
| 方向键 / WASD | 控制蛇移动 |
| 空格 | 游戏中暂停 / 继续；菜单中确认 |
| Esc | 打开暂停菜单；失败后退出 |
| E | 打开难度选择菜单（简单 / 普通 / 困难） |
| ↑↓ + Enter 或鼠标点击 | 菜单中移动选择并确认 |

## 玩法

- 吃红色食物 +10 分，蛇身变长
- 撞墙或撞到自己身体 → 游戏失败，弹出失败菜单（显示得分，可重新开始或退出）
- 按 E 选择三档难度，对应不同移动速度：简单 0.3s/步、普通 0.2s/步、困难 0.1s/步（可在 `snake.py` 顶部的 `SPEEDS` 中修改）
